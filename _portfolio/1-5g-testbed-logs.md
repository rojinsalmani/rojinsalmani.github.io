* **Hardware & Radio Link:** Configured USRP hardware and antennas to establish an over-the-air radio link for live 5G connectivity.
* **Standalone 5G Deployment:** Deployed and operated a standalone 5G network using **Open5GS** (core) and **srsRAN** (RAN) for end-to-end testing and operational data generation.
* **Log Processing Pipeline:** Built a preprocessing pipeline with **Regex** and **Drain3** to filter redundant entries and convert raw 5G logs into structured JSON while preserving event ordering and timing for LLM-based root-cause analysis.
