* Built isolated containerized network environments using **Linux network namespaces, Docker, and Mininet**, deploying **Open vSwitch (OVS)** for L2 switching and inter-subnet routing.
* Programmed dynamic SDN controllers in Python via **OpenDaylight** and **RESTCONF**, implementing Dijkstra's algorithm to automatically update OpenFlow rules in response to topology changes.
